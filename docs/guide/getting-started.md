# Getting Started

Want to run normly? See [Self-Hosting](self-hosting.md) — a Compose setup
starts a complete instance with one command.

Want to contribute? Start with the repository's
[contribution guide](https://github.com/normly/web-app/blob/develop/CONTRIBUTING.md), then read
[developer onboarding](developer-onboarding.md) for the component map and
practical first steps. The contribution guide includes setup and test
commands for humans; coding agents can also use its task-specific skills.

The first public release with a published knowledge base is planned for
December 2026.
